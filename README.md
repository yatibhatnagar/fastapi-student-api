# FastAPI Student CRUD API

This project is a simple Student CRUD API built using FastAPI.

## Features
- Create Student
- Get All Students
- Get Student by ID
- Update Student
- Delete Student

## Tech Stack
- FastAPI
- SQLAlchemy
- SQLite

## How to Run

1. Install dependencies:
   python -m pip install fastapi uvicorn sqlalchemy

2. Run server:
   py -m uvicorn main:app --reload

3. Open in browser:
   http://127.0.0.1:8000/docs
